# Final Prototype

## Student Apartment Finder Platform

The final deployed prototype is available at:

https://student-apartment-finder.onrender.com 

## Demo Access Notes

The prototype includes student apartment discovery, search and filters, apartment detail views, saved listings, basic inquiries, landlord listing submission, roommate posts, administrator review, and dashboard functions.

For the final demonstration, open the deployed link and show the following workflow:

1. Open the homepage and explain the target user and problem.
2. Open the Apartments page and use search or filters.
3. Open an apartment detail page and show price, distance, facilities, photos, contact, and map location.
4. Sign in with the prepared student account if saved listings or inquiry actions need to be demonstrated.
5. Sign in with the prepared landlord account to show the Add Listing form.
6. Sign in with the prepared admin account to show listing review, roommate moderation, and dashboard records.

Do not publish real passwords or private account details in this public repository. Demo credentials should be shared with the lecturer privately if needed.
