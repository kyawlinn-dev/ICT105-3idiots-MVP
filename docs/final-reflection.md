# Final Reflection

## Reflection on the Project

Developing the Student Apartment Finder Platform has been a valuable learning experience throughout the ICT105 module. From the initial business idea to the final MVP, our team experienced every stage of the software development process, including planning, requirement analysis, prototype development, user validation, testing, and documentation.

One of the most important lessons learned was the importance of gathering user feedback early. The MVP approach allowed us to validate our assumptions and improve the platform based on real user experiences rather than personal opinions.

Working as a team also strengthened our communication and collaboration skills. Each member contributed according to their responsibilities, including frontend development, backend implementation, and project documentation. Regular discussions helped us solve technical problems and complete each milestone on time.

From a technical perspective, we gained practical experience with modern web development technologies, database integration using Supabase, GitHub version control, and project documentation. We also improved our understanding of requirement traceability, startup metrics, and responsible IT practices.

If more development time were available, we would implement additional features such as user authentication, real-time messaging, interactive maps, and mobile application support to further improve the platform.

Overall, this project has improved both our technical knowledge and teamwork skills. It has demonstrated how a software project evolves from an initial concept into a working MVP through continuous testing, feedback, and improvement. The experience has prepared us for future software development projects and strengthened our confidence in applying the skills learned throughout the course.
