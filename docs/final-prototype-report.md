# Final Prototype Report

## Project Title

Student Apartment Finder Platform

## Overview

The Student Apartment Finder Platform is a web-based application developed to help university students search for suitable apartments near their campus. The project was created to simplify the apartment search process by providing a centralised platform where students can browse listings, filter apartments based on their preferences, view detailed information, and contact landlords.

Throughout the development process, the project followed the Lean Startup methodology by identifying user needs, validating assumptions through MVP testing, collecting user feedback, and continuously improving the prototype. The final prototype represents the complete implementation of the core features defined in the project requirements.

## Implemented Features

The final prototype includes the following features:

- Landing page introducing the platform
- Apartment listing page
- Search and filtering functionality
- Apartment detail page
- Contact landlord feature
- Administrator dashboard
- Apartment management (Add, Edit and Delete listings)
- Responsive user interface
- Supabase database integration

## User Validation

The prototype was evaluated through user testing to assess usability and functionality. Participants successfully completed the main user tasks, including browsing apartments, searching for suitable accommodation, viewing apartment details, and navigating the system. Feedback collected during testing was used to improve the user interface and overall user experience.

## Challenges

During development, several challenges were encountered, including frontend-backend integration, database configuration, interface consistency, and ensuring smooth navigation between pages. These issues were addressed through testing, debugging, and collaborative development.

## Final Outcome

The project successfully achieved its primary objective of providing a functional MVP for apartment searching. All core functional requirements were implemented and verified before the final submission. The platform demonstrates the complete user journey and provides a solid foundation for future development.

## Future Improvements

Although the MVP is complete, several improvements could be implemented in future versions:

- User authentication and account management
- Favourite apartment feature
- Real-time messaging between students and landlords
- Interactive map integration
- Online booking or reservation system
- Mobile application version
- Advanced filtering options
- Notification system for new apartment listings

## Conclusion

The Student Apartment Finder Platform successfully demonstrates the application of software development principles, user-centred design, and Lean Startup methodology. The project provides a practical solution to help students search for accommodation more efficiently while meeting the objectives and learning outcomes of the ICT105 module.
